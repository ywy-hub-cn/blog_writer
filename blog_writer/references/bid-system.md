# BID v2.1 — 综合运营文案分类标识系统

BID = 7 层组合标识，在动笔前确定，每层控制文章的一个核心走向。

```
BID = CO-WB-SE-GE-CL-LO-ST
      内容  WEB  SEO  GEO 集群 语言 模板
```

---

## ST — 结构模板层（6 点位）

| 值 | 模板 | 适用场景 |
|----|------|----------|
| 01 | 步骤指南模板 | How-to / Tutorial → Prerequisites → Step 1-N → Conclusion → CTA |
| 02 | 清单/列表模板 | Top N / Tips → Item 1-N → Summary → CTA |
| 03 | 概念定义模板 | What is X → Definition → Components → Types → Examples → CTA |
| 04 | 对比/评测模板 | X vs Y → Quick Table → Detailed Comparison → Pros/Cons → Verdict → CTA |
| 05 | 研究/报告模板 | Executive Summary → Methodology → Findings → Analysis → CTA |
| 06 | 完整指南模板 | TOC → Chapters (H2/H3) → Conclusion → Resources → CTA |
