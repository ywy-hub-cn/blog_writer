# 品牌文件格式规范

品牌文件放在 `brands/{品牌名}/` 目录下，文件名任意。S000 的 `setup_brand.py` 通过文件名关键词推断角色。

## 文件命名规则

文件名包含以下关键词时会自动识别角色：

| 关键词 | 角色 | 推荐文件名 |
|---|---|---|
| 品牌知识、知识库、knowledge、产品 | 品牌知识 | `{品牌名}品牌知识库.md` |
| 语气、调性、tone、voice、style | 语气调性 | `{品牌名}语气调性.md` |
| 禁用、forbidden、红线、黑名单 | 禁用词 | `{品牌名}禁用词清单.md` |
| 受众、画像、audience、persona | 受众画像 | `{品牌名}受众画像.md` |
| 评审、review、标准、criterion | 评审标准 | `{品牌名}评审标准.md` |
| 调用、usage、使用规则 | 知识库规则 | `{品牌名}知识库调用规则.md` |

## 品牌知识库.md 格式

```markdown
# {品牌名} 品牌知识库

官网：https://{域名}.com

品牌名称：{品牌名}

## 产品/服务
{产品描述}

## 核心关键词
- {关键词1}
- {关键词2}

## 其他内容
...
```

**必需字段：** `官网：https://...`（S000 自动提取 URL，用于 canonical 和内链）
**推荐字段：** 产品/服务描述、核心关键词列表

## 禁用词清单.md 格式

```markdown
# 禁用词清单

## 分类名称
- 禁用词1
- 禁用词2

## 分类名称
- 禁用词3
- 禁用词4
```

**规则：** 每行一个禁用词/短语，用 `- ` 或 `1. ` 开头。**不要**逗号分隔多个词在一行。

## 语气调性.md 格式

```markdown
# 语气调性

## 语气关键词
- {关键词1}
- {关键词2}

## 语气规则
- {规则1}
- {规则2}

## 示例
{示例内容}
```

## 受众画像.md 格式

```markdown
# 受众画像

## Persona 1
- 身份：
- 痛点：
- 偏好：

## Persona 2
...
```

## 其他文件

没有特殊格式要求，S000 会把完整原文写入 001 启动确认.md 的对应节。

## 最少文件要求

**最少只需要 1 个文件（品牌知识库.md）**。语气、禁用词、受众等文件没有时，对应步骤自动跳过。
