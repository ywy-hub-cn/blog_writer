# 品牌文件模板 — 用户参考

在你的 `brand_path` 目录下放以下文件（文件名可自定，S000 会自动识别）。**最少只需要 1 个文件**，没有的文件步骤会自动跳过。

---

## 推荐的品牌文件

| 建议文件名 | 角色 | 推荐程度 | 被谁读 |
|-----------|------|---------|--------|
| `{品牌名}品牌知识库.md` | 品牌知识（产品、定位、关键词） | ⭐ 强烈推荐 | S002 内容方案 |
| `{品牌名}语气调性.md` | 语气句式、品牌声音 | ⭐ 推荐 | S004 正文写作 |
| `{品牌名}禁用词.md` | 品牌红线、禁用表达 | ⭐ 推荐 | S004 正文写作 |
| `{品牌名}受众画像.md` | 目标读者、决策者画像 | 🔵 可选 | S002 内容方案 |
| `{品牌名}评审标准.md` | 内容质量评审维度 | 🔵 可选 | 预留 |
| `{品牌名}知识库调用规则.md` | 知识库使用、冲突裁决 | 🔵 可选 | 预留 |

---

## 示例：SMS Boosting 品牌文件命名

```
brand_path/
├── SMS Boosting品牌知识库.md        ← 会被识别为"品牌知识"
├── 语气调性指南.md                  ← 会被识别为"语气调性"
├── 禁用词清单.md                    ← 会被识别为"禁用词"
├── 受众画像.md                      ← 会被识别为"受众画像"
└── 评审标准.md                      ← 会被识别为"评审标准"
```

## 文件名识别规则

S000 通过文件名中的关键词推断角色：

| 文件名含有关键词 | 推断角色 |
|-----------------|---------|
| 品牌、知识库、产品、company、knowledge | 品牌知识 |
| 语气、调性、tone、voice、style | 语气调性 |
| 禁用、forbidden、红线、黑名单 | 禁用词 |
| 受众、画像、audience、persona | 受众画像 |
| 评审、review、标准、criteria | 评审标准 |
| 调用、规则、usage、knowledge-usage | 知识库规则 |
| 其他未被匹配的 | 其他 |
