# 文章质量评分规则

> 用于 S008 自审正文打分 和 S009 Gate校验

---

## 评分总则

| 分数 | 含义 |
|------|------|
| 9-10 | 信息具体、可执行、读完可直接行动 |
| 7-8 | 有价值，但还不够具体 |
| 4-6 | 内容正确但不够有用，泛泛而谈 |
| 1-3 | 拼凑感强，大量空话 |

---

## 1. 搜索意图匹配（1-10分）

**检查项：**
- 内容类型是否匹配搜索意图（操作型/信息型/商业型/导航型）
- 文章结构是否满足用户在该意图下的信息需求
- 是否有用户在该意图下实际想找的信息

**打分标准：**
| 分数 | 标准 |
|------|------|
| 9-10 | 完美对齐意图，读者找到答案 |
| 7-8 | 基本对齐，但有部分内容偏离 |
| 4-6 | 意图判断有偏差 |
| 1-3 | 意图错位 |

## 2. 关键词布局与语义覆盖（1-10分）

**检查项：**
- 主关键词是否出现在关键位置（标题/H2/首段）
- 次关键词/同义词/相关术语是否自然覆盖
- 是否避免关键词堆砌
- 是否有语义缺口

**打分标准：**
| 分数 | 标准 |
|------|------|
| 9-10 | 布局自然，覆盖充分 |
| 7-8 | 有覆盖，但个别字段偏弱 |
| 4-6 | 存在明显遗漏或堆砌 |
| 1-3 | 关键词混乱 |

## 3. 内容质量与信息价值（1-10分）

**检查项：**
- 是否有具体信息，而非空洞说教
- 是否提供了读者自己搜不到或需要整合的信息
- 每段是否在推进文章目标，而非填充字数
- 是否有真实案例、数据或步骤

**打分标准：**
| 分数 | 标准 |
|------|------|
| 9-10 | 信息具体、可执行、读完可直接行动 |
| 7-8 | 有价值，但还不够具体 |
| 4-6 | 内容正确但不够有用，泛泛而谈 |
| 1-3 | 拼凑感强，大量空话 |

## 4. 结构与可读性（1-10分）

**检查项：**
- 是否符合 8-9 年级阅读难度
- 语气是否像真人专家，而不是学术腔、企业腔或模板腔
- 是否有长短句变化，整体 flow 自然
- 段与段之间是否自然衔接
- 是否避免连续多个极短句、机械转折、僵硬跳跃
- 每个标题下第一句是否尽量直接回答该标题

**打分标准：**
| 分数 | 标准 |
|------|------|
| 9-10 | 阅读顺畅，扫读和细读体验都好 |
| 7-8 | 整体清楚，但部分段落偏硬 |
| 4-6 | 结构存在，但读起来费劲 |
| 1-3 | 阅读阻力大，像拼接稿 |

## 5. SEO 基础元素（1-10分）

**检查项：**
- Title 是否清晰、包含主词、长度合理
- H1 是否唯一且与主题一致
- URL 是否简洁、可读、包含主题信息
- Meta description 是否准确且有点击吸引力
- H2/H3 是否覆盖核心问题
- 内链、外链、图片 ALT、标题层级是否规范
- 问答型标题下是否尽快给出答案，利于抓取摘要

**打分标准：**
| 分数 | 标准 |
|------|------|
| 9-10 | 基础 SEO 要素完整且规范 |
| 7-8 | 大体规范，但细节一般 |
| 4-6 | 存在明显漏项 |
| 1-3 | 基础项大量缺失 |

## 6. E-E-A-T 与可信度（1-10分）

**检查项：**
- 是否有作者、团队、经验或评测方法说明
- 是否说明数据来源、研究依据或测试依据
- 是否避免无依据断言
- 是否用数字、案例或权威来源增强可信度
- 购买型或评测型文章是否解释"我们如何评估"

**打分标准：**
| 分数 | 标准 |
|------|------|
| 9-10 | 可信度高，信息支撑充分 |
| 7-8 | 基本靠谱，但信任信号不够强 |
| 4-6 | 像"知道一点"，但证据不足 |
| 1-3 | 缺乏可信支撑 |

## 7. 用户体验与转化能力（1-10分）

**检查项：**
- 首屏是否让读者快速知道能得到什么
- 内容推进是否自然，不频繁打断阅读
- 结尾是否完成三件事：收束全文、直接对读者说话、给出 CTA 或下一步动作
- CTA 是否自然，不生硬

**打分标准：**
| 分数 | 标准 |
|------|------|
| 9-10 | 读者读完知道该做什么，体验顺畅 |
| 7-8 | 体验不错，但结尾推动力一般 |
| 4-6 | 能看，但不太能转化 |
| 1-3 | 读完没有行动指引，或转化过于生硬 |

## 8. 原创性与差异化（1-10分）

**检查项：**
- 是否有自有观点、经验、数据或案例
- 是否只是在改写竞品内容
- 是否有更适合目标受众的结构和表达
- 是否存在多个小节高度同构、模板化明显的问题

**打分标准：**
| 分数 | 标准 |
|------|------|
| 9-10 | 有明显亮点和记忆点 |
| 7-8 | 内容合格，但独特性一般 |
| 4-6 | 同质化明显 |
| 1-3 | 几乎可被任何同类文章替代 |

## 9. AIGC 查重 / AI 痕迹（1-10分）

**检查项：**
- 工具层面是否存在明显重复、改写痕迹、与已发布内容高度相似
- 是否出现明显 AI 常见词、AI 套话或高风险句式
- 是否有大量同构句群或模板化段落
- 是否存在"表面流畅、实则空泛"的 AI 风格
- 是否有句子倒装、被动、模板腔、过度圆滑措辞
- 多个小节首句结构是否高度一致

**打分标准：**
| 分数 | 标准 |
|------|------|
| 9-10 | 明显像真人写作，工具和人工判断都低风险 |
| 7-8 | 偶尔有 AI 感，少量修改可修复 |
| 4-6 | 模板化明显，已经影响可信度 |
| 1-3 | AI 痕迹很重，不建议直接使用 |

## 10. 机械规范与引用规范（1-10分）

**检查项：**
- 列表结构是否统一，所有 bullet 是否从相同词性起手
- bullet 标题写法是否一致
- 冒号后是否接完整解释，而不是残句
- 引用是否真实、可核验，而不是直接采用未经核验的 AI 来源
- 文内是否说清来源主体和页面名
- 统计类、新闻类、研究类信息是否标注清楚出处
- 语法、拼写、标点是否稳定
- 括号内容是否仅作为附加说明，而非与主句混乱交织

**打分标准：**
| 分数 | 标准 |
|------|------|
| 9-10 | 格式统一，引用可靠，技术层面干净 |
| 7-8 | 存在小问题，但不影响整体 |
| 4-6 | 列表、引用、表达规范有多处问题 |
| 1-3 | 机械层面混乱，存在明显错误或来源风险 |
