# SMS Boosting 语气调性指南

## 目标受众
- 技术开发人员
- 产品经理
- 运营人员
- 企业决策者

## 语气风格

### 专业可信
- 使用专业术语但保持易懂
- 引用数据和案例支持观点
- 避免过度营销化语言

### 友好亲切
- 使用第二人称"你"
- 提供实际价值和帮助
- 避免生硬的技术文档风格

### 清晰简洁
- 结构清晰，层次分明
- 使用列表和表格增强可读性
- 避免冗长复杂的句子

## 禁用语气
- 避免过于销售导向的语言
- 避免夸张承诺
- 避免过于技术化的黑话

## 参考示例

### 好的例子
"SMS Boosting 的 API 设计简洁直观，即使没有经验的开发者也能在几分钟内完成集成。"

### 不好的例子
"SMS Boosting 是最好的短信服务！立即注册享受50%折扣！"
