一、基础信息

项值
Base URLhttp://服务器IP:8000（Nginx反代后用域名）
请求格式application/json（文件上传用 multipart/form-data）
响应格式{code, message, data, timestamp}
字段命名默认 snake_case；Java对接设 RESPONSE_CASE=camel 自动转驼峰
字符编码UTF-8

统一响应示例

{
  "code": 0,
  "message": "success",
  "data": { "task_id": "task_20260817_120000_abc123" },
  "timestamp": "2026-08-17T12:00:00"
}

二、鉴权

免登录接口（直接调用）

品牌管理、任务启动/查询/控制/日志/文件下载，均无需登录。

可选增强：.env 设 BLOG_WRITER_API_TOKEN=your-token，则上述接口需加请求头 X-API-Key: your-token

需登录接口（管理员）

节点CRUD、系统配置、统计信息，需先登录拿token，请求头加 Authorization: Bearer <token>

登录

curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"password": "admin123"}'
{
  "code": 0,
  "data": { "token": "eyJhbGciOi...", "role": "admin", "expires_in": 86400 }
}

三、完整对接流程

3.1 上传品牌资料

curl -X POST http://localhost:8000/api/brands/upload \
  -F "display_name=SMS Boosting" \
  -F "files=@品牌知识库.md" \
  -F "files=@语气调性指南.md"
{
  "code": 0,
  "data": { "brand_id": "sms-boosting", "display_name": "SMS Boosting", "file_count": 2 }
}
brand_id 由中文显示名自动转拼音生成，后续用 brands/<brand_id> 作为 brandPath

3.2 启动写作任务

curl -X POST http://localhost:8000/api/tasks/start \
  -H "Content-Type: application/json" \
  -d '{
    "brandPath": "brands/sms-boosting",
    "keywords": "SMS API integration guide",
    "mode": "auto",
    "priority": 2,
    "userNote": "面向企业开发者，侧重集成步骤",
    "callbackUrl": "https://your-platform.com/webhook",
    "callbackSecret": "your-secret"
  }'
字段必填说明
brandPath✅品牌资料路径，如 brands/sms-boosting
keywords✅文章关键词，≤500字符
mode-auto(默认) / supervised / manual
priority-1低 / 2中(默认) / 3高
userNote-附加写作要求
callbackUrl-任务终态回调地址
callbackSecret-Webhook签名密钥
{
  "code": 0,
  "data": { "task_id": "task_20260817_120000_abc123", "status": "queued" }
}

3.3 轮询任务状态（或等Webhook）

curl http://localhost:8000/api/tasks/task_20260817_120000_abc123
{

  "data": {
    "task_id": "task_20260817_120000_abc123",

四、Webhook回调

配置 callbackUrl 后，任务到达终态时POST通知。

回调请求

POST https://your-platform.com/webhook
Content-Type: application/json
X-Signature: sha256=<hex_digest>
{
  "task_id": "task_xxx",
  "status": "completed",
  "token_usage": 8766183,
  "keywords": "SMS API integration guide",
  "output_files": ["004 正文.md", "007 发布包.json"],
  "error": null
}

签名验证（必做，防伪造）

签名 = HMAC-SHA256(请求体原始字节, callbackSecret)，转十六进制小写，与 X-Signature 头比对。

Python

import hmac, hashlib
def verify(body: bytes, secret: str, sig: str) -> bool:
    expected = hmac.new(secret.encode(), body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, sig.removeprefix("sha256="))

Java

Mac mac = Mac.getInstance("HmacSHA256");
mac.init(new SecretKeySpec(secret.getBytes(), "HmacSHA256"));
String expected = HexFormat.of().formatHex(mac.doFinal(body.getBytes()));
return expected.equalsIgnoreCase(sig.substring("sha256=".length()));

Node.js

const crypto = require('crypto');
const expected = crypto.createHmac('sha256', secret).update(body).digest('hex');
return crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(sig.slice(7)));

五、任务控制接口

全部免登录。

方法路径说明
POST/api/tasks/{id}/pause暂停
POST/api/tasks/{id}/resume恢复暂停
POST/api/tasks/{id}/cancel取消（不可恢复，只能重跑）
POST/api/tasks/{id}/rerun-from从指定节点重跑
POST/api/tasks/{id}/resume-from断点续跑
POST/api/tasks/{id}/retry-node重试当前节点
DELETE/api/tasks/{id}删除任务记录及文件

六、人工审核接口

supervised/manual模式下任务进入 waiting_review 状态。

方法路径说明
GET/api/tasks/reviews/pending待审核列表
POST/api/tasks/{id}/review提交审核决策

decision 取值：approve(通过) / reject(驳回) / modify(修改后通过)

十、错误码大全

code含义常见原因处理建议
0成功--

  "site_url": "https://blog.yourcompany.com",
  "username": "editor",
  "app_password": "xxxx xxxx xxxx xxxx xxxx xxxx"

十二、常见问题排查

Q: 启动任务返回1006品牌不存在？

brandPath 要写 brands/<brand_id>，brand_id是拼音（如sms-boosting），不是中文。先调 GET /api/brands 确认。

Q: 任务一直queued不开始？

并发满了。调 GET /api/tasks/concurrency 看available，或调大 MAX_CONCURRENT_TASKS（默认5）。

Q: 任务failed了怎么看原因？

调 GET /api/tasks/{id}/logs 看最后几十行，常见是LLM API超时/密钥错/品牌文件缺失。

Q: token_usage数字很大正常吗？

单篇约500万-1500万Token（含多步重试），是累计值。费用按 ¥2/百万Token 估算。

Q: Webhook没收到回调？

检查callbackUrl是否公网可访问、服务器出站是否放行、回调接口是否返回2xx。任务终态才回调。

Q: 下载文件404？

文件名含中文/空格需URL编码；或任务还没生成该文件（看results中的output_files）。

Q: supervised模式任务卡住？

进入waiting_review等人工审核，调 GET /api/tasks/reviews/pending 查看，提交review决策。

Q: 响应字段是驼峰还是下划线？

默认snake_case。Java对接在 .env 设 RESPONSE_CASE=camel，所有响应自动转驼峰，请求体两种都接受。

完整接口定义见同目录 openapi.json 或运行中访问 /docs（Swagger UI）
